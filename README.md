# 👊 Punch Game

ATmega128 마이크로컨트롤러로 만든 **압력 센서 펀치 게임기**입니다.
제한 시간 30초 안에 압력 센서를 세게, 여러 번 때려서 점수 1000점을 모두 깎으면 성공입니다.
마이크로프로세서 수업 팀 프로젝트(4조) 결과물입니다.

## 게임 방법

1. 버튼을 눌러 게임을 준비합니다.
2. 압력 센서를 때리면 타이머가 시작됩니다. (30.00초부터 감소)
3. 때릴 때마다 **센서에 들어온 최대 힘 × 4** 만큼 점수가 깎입니다.
4. 시간이 끝나기 전에 점수를 0으로 만들면 성공, 못 하면 `FAIL`이 표시됩니다.
5. 클리어 시간이 LCD에 **1등 / 2등 기록**으로 저장됩니다.

## 주요 기능

- **7세그먼트(FND) 2세트** – 남은 점수와 남은 시간을 동시에 표시
- **타이머 인터럽트** – Timer2 오버플로 인터럽트로 0.01초 단위 카운트다운
- **ADC 압력 측정** – 8회 평균으로 노이즈를 줄이고, 한 번 칠 때의 최대값만 반영
- **LED 점멸** – 남은 시간이 줄수록 LED가 점점 빠르게 깜빡여 긴장감 연출
- **16x2 LCD 랭킹** – 가장 빠른 클리어 기록 1·2등 표시

## 하드웨어 연결

| 포트 | 연결 |
| --- | --- |
| PORTA | 점수 FND 데이터 |
| PORTB | FND 자리 선택 (하위 4비트: 점수, 상위 4비트: 시간) |
| PORTC | 시간 FND 데이터 |
| PORTD | 16x2 문자 LCD |
| PF0 (ADC0) | 압력 센서 입력 |
| PF1 / PF2~3 | 시작 버튼 / LED |

## 파일 구조

```
├── code.ino                               # 게임 소스 코드 (CodeVisionAVR C)
└── 마이크로프로세서 최종보고서(4조).hwp      # 최종 보고서
```

## 사용 기술

`ATmega128` `CodeVisionAVR` `C` `ADC` `Timer Interrupt` `7-Segment` `Character LCD`

> 확장자는 `.ino`지만 Arduino가 아닌 **CodeVisionAVR** 문법(`#include <mega128.h>`, `interrupt [TIM2_OVF]`)으로 작성되어 있습니다.
